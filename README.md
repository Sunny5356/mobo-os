# MOBO App (scaffold)

This workspace contains a minimal Flutter scaffold for the MOBO app described in the design documents.

To run (requires Flutter installed):

```
flutter pub get
flutter run
```

Files added:
- `lib/app` — app shell and theme
- `lib/features/home` — Home screen skeleton

This is a starting point. Next steps: implement modules, local DB (Drift), network client, and backend.
